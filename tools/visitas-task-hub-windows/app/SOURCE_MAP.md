# 情報源マップ

| 情報源 | 用途 | Hubに保存する内容 |
|---|---|---|
| GitHub担当Issue | 実装・調査の入口 | Issue番号、題名、URL、次の1手 |
| Slack Visitas関連 | 依頼、決定、ブロッカー | 要約、参照、次の1手のみ |
| Gmail Notta | 会議録の到着確認 | 会議名／日付の参照、Action Itemのみ |
| タスクボード／計画文書 | ロードマップ・優先順位 | 対応するHubタスクと根拠 |
| Codex / Claude handoff | 作業継続 | 実施内容、次の作業、変更ファイル、確認結果 |

本文や機密情報をHubへ転載せず、元の情報源へ戻れる参照と実行可能な次の1手を残す。
